# Corporate Site LP（コーポレートサイト LP） [2周目]

CODEJUMP 初級編「コーポレートサイト LP」課題の2周目の制作リポジトリです。

## 概要

渋谷のWeb制作会社によるコーポレートサイト（1ページLP）のコーディングを行っています。BEM記法とSCSSを用いた効率的なCSS設計、スマホ表示時の「お問い合わせ」ボタン非表示や要素の並び順制御、高さ固定画像や高さズレ配置などを実装します。

## コーディング仕様

- **コンテンツ幅**: 
  - メインビジュアル / About: 全幅（100%）
  - その他セクション: 1000px
- **セクションタイトル**: 
  - 英字・日本語の2段構成（英字は `letter-spacing` で文字間隔を調整）
- **News**: 
  - 3分割＋罫線配置、日付に `<time>` タグを使用
- **About / Company**: 
  - 画像高さ 400px 固定
- **Business**: 
  - 高さをずらした横並び配置（スマホ時の並び順を意識したコーディング）
- **レスポンシブ**: 
  - ブレークポイント: 900px
  - スマホ時: 右上「お問い合わせ」ボタン非表示

## 使用技術

- HTML5
- SCSS / CSS3
- BEM (CSS設計)
- Live Sass Compiler
- Git / GitHub
